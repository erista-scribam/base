# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch and backported when practical. Pre-release or unsupported branches may not receive patches.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report privately by one of:

1. **GitHub Security Advisories** — Use **Security → Advisories → Report a vulnerability** on the public GitHub repository (preferred once advisories are enabled).
2. **Maintainer contact** — Email or direct message the repository owner if advisories are not yet available.

Include:

- Description and impact
- Steps to reproduce
- Affected versions or commits
- Suggested fix if you have one

We aim to acknowledge reports within a few business days. We will coordinate disclosure and credit when appropriate.

## Scope

In scope: Scribo Prosa desktop app, Tauri/Rust persistence, dependencies shipped with releases, and project infrastructure (CI, release workflows).

Out of scope: Third-party services not operated by this project, and social engineering against individuals.

## Safe harbor

Good-faith security research that follows this policy will not be pursued as a violation of applicable law or terms.
