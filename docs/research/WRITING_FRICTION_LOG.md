# Writing friction log (Phase 0)

Record **concrete friction** from real Scribo Prosa sessions. This grounds the roadmap in evidence, not competitor features.

## How to add an entry

Copy the template below. One entry per distinct problem. Link manuscripts or steps to reproduce when possible.

**Distinguish:**

- **Process problem** — The writer's workflow needs support (revision compare, research recall, …).
- **Implementation bug** — Current Prosa behavior is wrong vs [invariants.md](../product/invariants.md).

---

## Template

```markdown
### YYYY-MM-DD — Short title

- **Context:** (project type, length, Classic vs Markdown, library path or internal)
- **Goal:** What you were trying to do
- **Friction:** What interrupted flow or risked trust
- **Kind:** process | bug | both
- **Severity:** blocking | frequent | occasional
- **Workaround:** If any
- **Roadmap phase:** 0–7 or "invariant"
- **Follow-up:** Issue, spec, or test
```
