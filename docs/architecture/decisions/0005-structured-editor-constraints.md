# ADR 0005: Structured editor constraints

**Status:** Accepted  
**Date:** Early milestone (recorded 2026-10-26)

## Decision

TipTap StarterKit is trimmed (no generic code blocks / arbitrary horizontal rules). Scene breaks are a dedicated block node (`Mod-Shift-S`).

## Consequences

- Document structure stays aligned with Prosa semantics.
- New block types require schema and model updates.
