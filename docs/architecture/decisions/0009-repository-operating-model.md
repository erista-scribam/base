# ADR 0009: Repository-first operating model

**Status:** Accepted  
**Date:** 2026-10-26

## Context

The project needed auditable, public-ready workflow without retroactive issue/PR manufacture.

## Decision

Adopt plan 004 as the engineering operating model: canonical docs in `docs/`, GitHub for coordination, [project-baseline.md](../../engineering/project-baseline.md) as opening balance, prospective workflow only.

## Consequences

- [operating-model.md](../../engineering/operating-model.md) is the living summary; full plan in [plans/completed/004](../../plans/completed/004-workflow-total-revamp.md).
- [AGENTS.md](../../../AGENTS.md) and [CONTRIBUTING.md](../../../CONTRIBUTING.md) align with this model.
