# Support

Scribo Prosa is under active development. There is no paid support tier.

## Getting help

1. **Documentation** — Start with [README.md](README.md) and [docs/README.md](docs/README.md).
2. **Bug reports** — Open a GitHub Issue using the bug template (once the repository is public).
3. **Feature ideas** — Use the feature request template; align with [docs/product/philosophy.md](docs/product/philosophy.md).
4. **Security** — See [SECURITY.md](SECURITY.md); do not file public issues for vulnerabilities.

## Building from source

```bash
pnpm install
pnpm verify:all
pnpm tauri:dev
```

Requires Node.js 22+, pnpm 10.x, and Rust with [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/).
